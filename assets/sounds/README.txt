Sound effects are synthesized in code at start-up (scripts/autoload/sound_manager.gd),
so the game needs no audio files and has no licensing concerns.

To replace any effect with your own recording, put a file here named after it:
  click, pick, drop, swap, correct, combo, locked, wrong, tick, hint, preview,
  pause, shuffle, star, win, fail, unlock
with extension .wav, .ogg or .mp3 (for example "win.ogg"). It is used automatically.
